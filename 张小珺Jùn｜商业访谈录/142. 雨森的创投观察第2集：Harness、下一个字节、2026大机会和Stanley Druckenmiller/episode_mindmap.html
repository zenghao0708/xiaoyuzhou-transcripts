142. 雨森的创投观察第2集

Harness、下一个字节、2026 大机会与 Stanley Druckenmiller

AI 创业从模型叙事进入系统叙事

强观点需要不断更新。真正的机会不只在模型能力，而在 Harness、任务价值、Agent 原生基础设施和组织形态。

判断更新

Strong opinions, weakly held有明确判断，但不被公开表达绑住；外部前提变化后要更新。
Return 时间线后移C 端订阅和广告低于预期，coding 企业价值改变回报节奏。
能力突破像水烧开从不可用到可用常常跨过阈值，事前难预测哪一版会触发。

模型公司

Anthropic 的组织力围绕 coding 方向 top-down 执行，价值观和资源更集中。
OpenAI 的创新种子自下而上探索多，但项目持续性和组织收束更分散。
叙事持续轮换OpenAI、Gemini、Anthropic 和 Codex 的领先感会阶段性切换。

Harness

不只是壳包含 context、runtime、tooling、权限、数据回流和任务轨迹。
像 AI 时代的 OS模型更像处理器，Harness 决定模型如何进入真实工作流。
数据飞轮Agentic 任务轨迹比普通聊天更接近训练和产品改进需要的信号。

产品指标

DAU 不再唯一生产力产品的价值在于完成任务，而不是让用户反复打开。
高价值任务少数深度用户和高价值工作，可能比大规模浅层访问更重要。
魔法时刻AI 产品靠真实体感传播，补贴和投放不能替代好用。

Agent 世界

让人拥有 Agent第一波机会是降低拥有和管理 Agent 的门槛。
让 Agent 适应人类软件支付、账号、沙盒、computer use 都是过渡期基础设施。
建设 Agent 原生设施未来需要更适合 Agent 的 API、CLI、微支付和权限系统。

组织与创业

团队变小AI native 公司在 PMF 阶段需要的人更少，职能边界更模糊。
下一个字节不像字节移动互联网时代的 DAU、补贴和封闭生态，可能需要被重写。
创新需要练习创业者要主动训练自己看新问题，而不是只复用旧打法。
